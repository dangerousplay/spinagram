spinagram 0.1 is the first stable release. Beyond boxes and arrows, it brings the features that turn a
diagram into something you can hand to anyone: new diagram types, real styling, diagrams that explain
themselves, a catalog to find them, and AI agents that can draw them for you.

## Flowcharts, state machines and swimlanes

Until now spinagram drew *structure*: what runs where. It now draws *behavior*: what happens, in what
order, and who does it. Three builders speak the language of each diagram type, and a new built-in
`layered` engine ranks the flow, routes arrows at right angles and draws loops round the side.

```python
from spinagram import Flowchart

fc = Flowchart("B01", "Checkout")
card, valid = fc.io("Read card"), fc.decision("Card valid?")
fc.start() >> card >> valid
valid.yes(fc.process("Charge card")) >> fc.end()
valid.no(fc.io("Show error")).to(card, "retry")
```

## Style anything with CSS

Diagrams can now be styled with the CSS you already know: selectors, classes, the cascade and custom
properties. Keep the diagram about *what* and move *how it looks* into a stylesheet that every diagram
of your team shares.

```css
node.critical { fill: #FEE2E2; stroke: #DC2626; stroke-width: 4 }
edge.async    { stroke: #F59E0B; stroke-dasharray: 6 4; marker-end: open-arrow }
group.vpc node::title { color: var(--brand) }
```

The same rules render in SVG, PowerPoint and Figma. Dashes, shadows and arrowhead kinds come out as
native PowerPoint and Figma properties, not pictures.

**Why it matters:** rebranding a whole deck is one file change, and you never have to guess where a colour
came from. Press **Inspect** in `spinagram serve` and click any element to see the rule that set each
value. Saving the stylesheet re-renders every diagram that uses it.

## Diagrams that explain themselves

A diagram that needs a presenter stops working the moment it is forwarded. Four annotations keep the
explanation on the slide:

| Annotation | One line of code | What it adds |
|---|---|---|
| Numbered steps | `a.to(b, "SQL", step="Order is stored")` | A badge on the arrow and a line in a **Steps** panel |
| Legend | `d.add_legend()` | Every class, style and line type in the diagram, decoded |
| Callout | `d.callout(db, "Snapshots every 6 h", kind="tip")` | A bubble with a leader line, placed on a free side |
| Note | `d.note("Why Aurora", text="...", variant="card")` | Sticky notes, cards and quotes for the narrative |

## A catalog for all your diagrams

`spinagram serve` grew from a single preview into a browsable catalog:

- **Diagrams** page: every diagram as a live thumbnail, grouped by category, with search and tag chips.
- **Themes** page: each theme shown on a sample diagram, so you pick one by looking, not by reading tokens.
- **Icon packs** page: twelve sample icons per pack, the full searchable grid one click away.
- A sidebar with the ten diagrams you opened last.

You do not have to tag anything: a diagram full of `aws:` icons lands in **AWS**, one with `k8s:` icons in
**Kubernetes**. Declare `category=` and `tags=` when you want your own, and filter on the command line
with `spinagram render specs/ --tag kubernetes`. [Live UI →](/docs/tools/live-ui)

```bash
spinagram serve examples/
```

## Ask your AI agent for a diagram

spinagram now ships agent skills: the instructions, recipes and worked examples a coding agent needs to
write, style and check diagrams well. Install them once and ask in plain words.

```bash
spinagram skills install --agent claude      # or codex, copilot, cursor, gemini, opencode
```

> *"Draw our checkout service on AWS for the architecture review: ALB, ECS, Aurora and SQS, with the
> request path numbered. Use our brand.css and export to PowerPoint."*

The agent writes the spec, runs `spinagram check`, fixes what it reports and renders the slide.

## Less boilerplate in Python

Python is the default way to write a diagram, and it now needs fewer lines:

- **No registration line.** `spinagram render` and `serve` load every `Diagram` a file creates; `diagram = d`
  is no longer needed.
- **One size for many boxes.** `Diagram(..., node_size=(230, 84))` or `with d.group(..., node_size=(150, 60))`
  sizes every box created inside; `size=(w, h)` sets one box. No more `**N` dictionaries.

```python
from spinagram import Diagram

d = Diagram("K01", "Cluster", node_size=(230, 84))
with d.group("Pods", node_size=(150, 60)):
    pods = [d.box(f"web-{i}", icon="k8s:pod") for i in "abc"]
d.box("Ingress", icon="k8s:ing") >> pods
```

## Arrows that stay readable

Automatic layout now looks after the details that used to need hand-tuning:

- **Labels never sit on an arrowhead.** Edge labels move off the tip of the arrow, beside or above the line,
  and between two boxes the gap grows to fit the label and its arrowhead (unless you set the `gap` yourself).
- **Arrows don't pile up.** An edge that has to go around something picks a side of the box no other edge
  uses, so two arrowheads never land on the same spot.
- **Routes keep their distance.** Orthogonal routes stay clear of box borders and group captions instead of
  grazing them, and a simple elbow that would cut through a box is re-routed around it.
- **`spinagram check` catches the rest.** It now reports a label that hides an arrowhead, a label drawn over
  a box, and an edge drawn through a box it does not connect, with what to change.

```text
L01:e2: edge — edge passes through box vault-1 — use layout route: ortho, another direction, or via points
EX2:e3: label — label hides its own arrowhead — widen the gap between the boxes or place the label with label_at
```

## Four more icon packs: AI, CNCF, products and languages

`ai` covers the AI stack (OpenAI, Claude, Gemini, Ollama, Bedrock, LangChain, MCP). `cncf` brings the official
icons of about 240 CNCF projects (Cilium, Argo, Envoy, OpenTelemetry, Falco, Kyverno, KEDA, Flux, cert-manager…),
with white variants that switch on automatically on dark fills. `logos` adds about 2,000 technology logos
(Terraform, GitHub Actions, Datadog, GitLab, JFrog), and `devicon` 560 languages and developer tools. That makes
thirteen packs, all one argument away.

```python
d.box("Claude", icon="ai:claude")
d.box("Cilium", icon="cncf:cilium")
d.box("Terraform", icon="logos:terraform")
d.box("Rust", icon="devicon:rust")
```
