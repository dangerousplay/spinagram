## Smaller releases

- **0.2.0.** In `spinagram serve`, inspect mode highlights the element under the pointer and shows the file
  and line that declare it. **Show in code** jumps to that line. The Recent sidebar folds to a rail.
- **0.1.2.** The code panel starts collapsed and folds with `e`.
- **0.1.1.** `spinagram --version`. New AI, CNCF, technology and Devicon logo packs. `size=(w, h)` on any node
  and `node_size=` on a diagram or group. Python specs need no `diagram = d` line.
