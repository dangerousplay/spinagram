```bash
spinagram render specs/ --theme ../my-theme -f svg,png,pptx,figma -o out/
spinagram check specs/ --theme ../my-theme        # text overflow and layout report
spinagram check specs/ --styles --select .critical # why elements look the way they do
spinagram render specs/ --tag kubernetes           # only diagrams tagged kubernetes
spinagram facts specs/                             # facts used, per diagram
spinagram layout spec.yaml -o frozen.yaml          # freeze automatic positions
spinagram serve specs/                             # live-reload UI
spinagram icons search "load balancer"             # icon pack management
spinagram vectorize icons/ -o vector/              # trace PNG icons into SVG
spinagram deck deck.yaml -o slides.html            # HTML presentation
spinagram skills install --agent claude            # agent skills, see AI agent skills
spinagram mcp install -a claude                    # MCP server for agents, see MCP server
spinagram mcp --http 8766                          # the MCP server over streamable HTTP
python -m spinagram render specs/                  # the same CLI from any Python with spinagram
```

`paths` are spec files or directories (`*.yaml`, `*.py`). A `_defaults.yaml` in a directory sets
defaults for every spec in it.

| Option | Commands | Meaning |
|---|---|---|
| `-t, --theme` | render, check, facts, layout, deck, serve | Theme directory or name, see [Themes by name](/docs/customize/themes#themes-by-name) (env `SPINAGRAM_THEME`) |
| `--only ID...` | render, check, facts, layout | Diagram ids to include |
| `--tag TAG` | render, check, facts, layout | Only diagrams with this tag, declared or inferred from icons; repeat to require several |
| `--category NAME` | render, check, facts, layout | Only diagrams in this category (case-insensitive) |
| `--layout ENGINE` | render, check, facts, layout, serve | Engine for specs with `layout:` (`flex`, `dot`, `elk`, `d2`; env `SPINAGRAM_LAYOUT`) |
| `-f, --formats` | render | Comma list from `svg`, `png`, `pptx`, `figma`, `figjam`, `excalidraw` |
| `-o, --out` | render, layout, vectorize, deck | Output directory or file |
| `--no-gallery` | render | Skip `index.html` |
| `--fonts subset\|embed\|link` | render | SVG and PNG fonts: `subset` (default) embeds only the characters drawn, `embed` the whole font files, `link` none (a Google Fonts `@import`) ([details](/docs/share/outputs#svg-fonts)) |
| `--styles` | check | Explain each element's computed style: matching rules, overrides, inheritance ([details](/docs/customize/css-reference#inspect-computed-styles)) |
| `--select SELECTOR` | check | With `--styles` or `--json`: only elements matching a CSS selector |
| `--json` | check | Print the style report as JSON |
| `--color auto\|always\|never` | check | Colour the style report (`auto`: a terminal without `NO_COLOR`) |

## What `check` reports

| Kind | Meaning |
|---|---|
| `overflow-x`, `overflow-y` | Text wider or taller than its box |
| `layout: overflow` | The automatic layout does not fit its area |
| `label` | An edge label hides an arrowhead, or covers a box |
| `edge` | An edge is drawn through a box it does not connect |
| `style` | A stylesheet error, an unknown property or a font the theme does not embed |
| `behavior` | A decision with one branch, a fork with one branch, a state region without an initial state |
| `legend`, `steps`, `callout`, `annotations` | Annotation problems, see [Annotations](/docs/customize/annotations#checks) |
| `edge-crosses-zone-header`, `icon-overlaps-text` | An edge through a zone header, an icon over its box's text (P0) |
| `text-scale-mismatch`, `icon-generic-for-service`, `glyph-mapped` | Uneven text sizes in a row, a generic icon on a named cloud service, a character replaced by the theme glyph map (P2) |

Hand-placed diagrams get the layout checks too (`zone-underused`, `edge-crossings`, …); the
[Layout engine](/docs/write/layout-engine#check-and---fix) guide lists every kind, its severity and its fix.

`check` exits non-zero when it finds anything, so it can gate a pull request.

## `mcp`

| Option | Meaning |
|---|---|
| `-t`, `--layout`, `--formats` | Defaults for every tool call (`--formats` is a comma list; default `svg,png`) |
| `--root DIR` | Folder every tool path must stay inside (default: the current folder) |
| `--http PORT`, `--host` | Serve streamable HTTP at `http://HOST:PORT/mcp` instead of stdio (host default `127.0.0.1`) |

`spinagram mcp install` writes the server into an agent's config. See [MCP server](/docs/tools/mcp) for both.

## Environment variables

| Variable | Effect |
|---|---|
| `SPINAGRAM_THEME` | Default theme |
| `SPINAGRAM_THEME_PATH` | Directories searched for themes by name (`<dir>/<name>/theme.yaml`), separated by `:` (`;` on Windows) |
| `SPINAGRAM_LAYOUT` | Default layout engine override |
| `SPINAGRAM_CACHE` | Cache directory for icon packs (default `~/.cache/spinagram`) |
| `SPINAGRAM_OFFLINE=1` | Never download icon packs |
| `SPINAGRAM_ICON_PACKS` | Extra icon pack registry file |
| `SPINAGRAM_VECTORIZE=0` | Do not trace PNG icons into SVG |
| `SPINAGRAM_PPTX_SVG=raster` | PowerPoint gets PNG icons only |
