spinagram turns a short description of your system into a finished diagram: laid out, styled,
annotated and ready for a slide deck. You say **what is connected to what**. spinagram picks the
sizes and positions, draws the icons and routes the arrows, then hands you SVG, PNG, PowerPoint
slides with native shapes, and Figma or FigJam nodes you can keep editing.

![One source: Python or YAML, rendered by spinagram to SVG, PNG, PowerPoint and Figma](/assets/overview.svg)

## Why people use it

- **You never drag a box.** Boxes grow to fit their text and icon, groups wrap their children,
  arrows avoid the boxes. Change one line and the whole picture re-flows.
- **The output stays editable.** PowerPoint gets real shapes with connectors bound to them: move a
  box and its arrows follow. Figma gets real frames. Nobody has to redraw a screenshot.
- **Diagrams explain themselves.** Numbered steps, callouts and an automatic legend live on the
  slide, so the diagram still makes sense when you are not in the room to present it.
- **One look across the whole deck.** A theme or a CSS stylesheet sets colours, fonts and line
  styles for every diagram at once.
- **Reviewable like code.** Diagrams are text files: diff them, review them in pull requests, and
  let `spinagram check` catch overflowing text before anyone sees it.
- **Your AI agent can draw them.** spinagram ships skills that teach coding agents to write, style
  and check diagrams for you.
