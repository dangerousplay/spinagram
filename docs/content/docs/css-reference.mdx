title: CSS by backend
description: What each output format does with every CSS property, with rendered examples, the style inspector and live reload.
---

One stylesheet styles every output. SVG and PNG draw every value exactly (PNG is rendered from
the SVG). PowerPoint and Figma draw them as native, editable properties; where a format has no
equivalent, spinagram draws the nearest one and `check` or the render prints one warning naming
the backend, the property and the value.

## Support matrix

✅ exact · ≈ nearest equivalent (see note) · — ignored

### Nodes, groups, regions and lanes

| Property | SVG / PNG | PowerPoint | Figma / FigJam | Notes |
|---|:-:|:-:|:-:|---|
| `fill` | ✅ | ✅ | ✅ | Solid colours. |
| `fill-opacity` | ✅ | ✅ | ✅ | Alpha on the fill only; the outline stays opaque. |
| `stroke` | ✅ | ✅ | ✅ | |
| `stroke-width` | ✅ | ✅ | ✅ | |
| `stroke-dasharray` | ✅ | ✅ | ✅ | PowerPoint stores the pattern relative to the line width (`a:custDash`), so it scales with `stroke-width` exactly as in SVG. |
| `border-radius` | ✅ | ✅ | ✅ | Boxes and groups. Behavior symbols (states, decisions, …) keep their own geometry. |
| `opacity` | ✅ | ≈ | ≈ | SVG fades the whole element. PowerPoint blends the fill with the slide background; Figma sets the fill paint opacity. Text and outline stay opaque in both. |
| `box-shadow` | ✅ | ✅ | ✅ | One shadow: `offset-x offset-y blur colour`. Spread and `inset` are ignored. PowerPoint gets an outer shadow (`a:outerShdw`), Figma a drop-shadow effect. |

### Text: `::title`, `::body`, `::label`

| Property | SVG / PNG | PowerPoint | Figma / FigJam | Notes |
|---|:-:|:-:|:-:|---|
| `color` | ✅ | ✅ | ✅ | Inherited from groups. |
| `font-size` | ✅ | ✅ | ✅ | Feeds automatic sizing, so boxes grow to fit. |
| `font-weight` | ✅ | ≈ | ≈ | PowerPoint has bold or regular only; Figma uses the style the theme maps to that weight (`fonts.*.figma`). |
| `font-style` | ✅ | ✅ | ✅ | `italic` or `normal`. |
| `font-family` | — | — | — | Checked, not applied yet: text keeps the theme font, and a family the theme does not embed is warned about once. |

### Edges

| Property | SVG / PNG | PowerPoint | Figma / FigJam | Notes |
|---|:-:|:-:|:-:|---|
| `stroke`, `stroke-width` | ✅ | ✅ | ✅ | |
| `stroke-dasharray` | ✅ | ✅ | ✅ | |
| `opacity` | ✅ | ✅ | ✅ | PowerPoint puts an alpha on the line colour. |
| `marker-start`, `marker-end`: `arrow`, `open-arrow`, `diamond`, `circle`, `none` | ✅ | ✅ | ✅ | PowerPoint arrowheads `triangle`, `arrow`, `diamond`, `oval`; Figma stroke caps. |
| `marker-*: open-diamond` | ✅ | ≈ | ≈ | Drawn as a filled diamond, with a warning. |
| `marker-*: bar` | ✅ | ≈ | ≈ | No bar arrowhead in either: the end is drawn without a marker, with a warning. |

### Values

| Form | Example |
|---|---|
| Hex, `rgb()`, `rgba()`, CSS names | `#DC2626`, `rgba(0, 0, 0, .25)`, `teal` |
| Theme tokens | `fill: primary-soft` |
| Custom properties | `:root { --brand: #0F766E }` then `var(--brand)`; `var(--warning)` falls back to the theme token `warning`; `var(--x, #fff)` takes a fallback |
| Lengths | `4`, `4px` (pixels on the 1920 × 1080 canvas) |

An unresolvable colour stops the render with file, line and selector. An unknown property, an
empty or invalid value and a negative width are skipped with a warning.

```bash
spinagram check --styles examples/styling/styled.py --select "#payments"
```

| Option | Effect |
|---|---|
| `--styles` | Print the style report before the usual checks |
| `--select SELECTOR` | Only elements matching the selector (`".critical, edge.async"`) |
| `--json` | The same report as JSON, the format the live inspector reads |
| `--color auto\|always\|never` | Colour and swatches; `auto` colours a terminal unless `NO_COLOR` is set. Without colour, overridden declarations end in `(overridden)` |

Plain `spinagram check` also lists selectors of your own stylesheets that match nothing as
`info: unused selector` lines. They are hints, not issues: the exit code ignores them. Theme
stylesheets are not checked this way, since a theme styles kinds a diagram may not use.

## Live inspector and live reload

In [`spinagram serve`](/docs/live-ui), press **Inspect** (or `i`). Hovering outlines the element
under the pointer; a click opens its classes, attributes, computed style and source rules, the
same report as `check --styles`. With nothing selected, the panel lists the element tree, the
cascade order and unused selectors. `Esc` clears the selection; dragging still pans.

![The live inspector on the styled payments diagram](/assets/css/inspector.webp)

Saving a stylesheet re-renders exactly the diagrams whose cascade includes it, and the inspector
refreshes with the selection kept. That covers `.css` files next to the specs, stylesheets
referenced from elsewhere (their folders are watched too), inline `css:` in a folder's
`_defaults.yaml` and the theme's `theme.css`, which re-renders everything.
