The four slides on this page are **the same Python code**. Each one attaches a different stylesheet. The
diagram says what each element *is* (`class_="service"`, `class_="store"`, `class_="async"`); the stylesheet
decides what that looks like. Rebrand a whole deck by swapping one file.

## Techniques worth stealing

| Effect | CSS |
|---|---|
| Dark canvas | Wrap the diagram in a group and style it: `group.canvas { fill: #070B16; fill-opacity: 1 }` |
| Glow | A shadow with no offset: `box-shadow: 0 0 32px rgba(244, 114, 182, 0.55)` |
| Lifted card | A soft offset shadow: `box-shadow: 0 6px 14px rgba(15, 23, 42, 0.10)` |
| Layout-only group | Hide it: `group.bare { fill-opacity: 0; stroke-width: 0 }` |
| Async events | `edge.async { stroke-dasharray: 6 5; marker-end: open-arrow }` |
| One palette | Custom properties: `:root { --brand: #6D28D9 }`, then `stroke: var(--brand)` |
| Style by context | `group.cluster node::title { color: #F8FAFC }` |

Edge label pills always use the canvas colour (white by default), so give labels a dark `color` even on a
dark canvas, as Blueprint does.

## Work on a look live

```bash
spinagram serve examples/looks/
```

Edit a `.css` file and every diagram that uses it re-renders. Press **Inspect** (or `i`) and click an element
to see which rule set each value, or ask on the command line:

```bash
spinagram check examples/looks/ --styles --select ".hero"
```
