## Decision slides

**Use it for:** architecture decision records, review summaries, open questions.

Notes come in three variants: `card` (with an icon and an accent bar), `quote` and `sticky`. Give them
coordinates for a designed, pixel-exact slide:

```python
d.note("Aurora PostgreSQL", text="Managed backups and point-in-time recovery.",
       variant="card", icon="aws:amazon-aurora", x=80, y=200, w=540, h=210)
d.note("Werner Vogels", text="Everything fails, all the time.", variant="quote", x=80, y=520, w=1150, h=300)
d.note("Open question", text="Do we need a second region before the EU launch?", x=1300, y=520, w=540, h=140)
```

## Diagrams from data

**Use it for:** diagrams generated from an inventory, a CMDB or another tool.

Everything works as YAML too, which any program can write. Edges have a one-line shorthand:

```yaml
id: Q01
title: Web app
nodes:
  - {id: lb, title: Load balancer, icon: "aws:alb"}
  - {id: api, title: API, text: FastAPI, icon: "terrastruct:python"}
edges:
  - "lb -> api: HTTPS"
```

```bash
spinagram render specs/ -f svg,pptx -o out/
```
