**Use it for:** network designs, VLAN plans, homelab documentation.

The `network` pack has device symbols (`network:l3-switch`, `network:firewall`, `network:internet`) and the
`selfhosted` pack has logos for self-hosted software (`selfhosted:proxmox`, `selfhosted:truenas`,
`selfhosted:pihole`). Groups become VLANs, racks or sites:

```python
with d.group("VLAN 10 · edge", class_="vlan dmz", direction="down"):
    internet = d.box("Internet", text="ISP fibre", icon="network:internet")
    fw = d.box("Firewall", text="OPNsense", icon="selfhosted:opnsense")
```
