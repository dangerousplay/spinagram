## Flowchart

**Use it for:** runbooks, approval rules, "what happens when the card is declined".

Every verb draws the right symbol, and decisions get `.yes()` and `.no()`:

<Example id="b01" />

Keep the happy path on `>>` chains and branch off with `.no()`; the layout keeps the main line straight.
`spinagram check` warns about a decision with only one branch.

## State machine

**Use it for:** order, ticket, deployment or account lifecycles.

`state.on(event, target, guard=, action=)` labels transitions the UML way, `event [guard] / action`.
Composite states and parallel regions nest with `with`.

<Example id="b02" />

## Process with swimlanes

**Use it for:** cross-team processes, hand-offs, "what happens after the customer clicks Buy".

Put actions inside `with act.lane("Team"):` and let `with act.sequence():` connect them in order. A
`parallel()` block draws the fork and join bars.
