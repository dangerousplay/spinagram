**Use it for:** design reviews, onboarding docs, the "how it works" slide.

1. Start with the systems and the arrows between them. Leave out the groups.
2. Add icons: `icon="aws:s3"`, `icon="gcp:cloud-run"`, `icon="k8s:pod"` ([finding icons](/docs/examples/icons)).
3. Wrap boxes in `with d.group(...)` blocks, from the outside in: account, region, VPC, zone, subnet.
4. Number the request path with `step=` and add `d.add_legend()`.
