**Use it for:** design reviews, onboarding docs, the "how it works" slide.

1. Start with the systems and the arrows between them. Leave out the groups.
2. Add icons: `icon="aws:s3"`, `icon="gcp:cloud-run"`, `icon="k8s:pod"` ([finding icons](/docs/examples/icons)).
3. Wrap boxes in `with d.group(...)` blocks, from the outside in: account, region, VPC, zone, subnet.
4. Number the request path with `step=` and add `d.add_legend()`.

## Editable on the canvas

A hand-placed YAML diagram in the AWS group conventions: AWS Cloud, AWS account, Region, VPC and public and private
subnets, each group with its own icon and outline (the `aws-*` zone styles), and Users outside the cloud. Open it with
`spinagram serve examples/showcase/editable_platform.yaml`, press `c`, and drag nodes between subnets, drag a zone to
move its children, group nodes as a row or column, drop icons or provider zones from the palette, change a zone's
style from the bar, and undo with Ctrl/Cmd+Z.
