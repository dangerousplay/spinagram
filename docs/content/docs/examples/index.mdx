Every picture here is rendered by spinagram from a file in
[`examples/`](https://github.com/dangerousplay/spinagram/tree/main/examples). Pick the one closest to what you
need, copy it, and open it in the live preview:

```bash
spinagram serve examples/looks/      # any file or folder; re-renders on every save
```
