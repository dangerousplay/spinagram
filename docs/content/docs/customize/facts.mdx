---
title: Facts
description: Numbers with traceable sources in every render.
---

Point a diagram, or a folder via `_defaults.yaml`, at a facts JSON file with
`facts: path/to/facts.json` and `locale: pt-BR`. Then write numbers as `{{fact_id}}`, or
`{{fact_id|pct1}}` to override the format, in any text.

A fact has `id`, `label`, `format`, and either a `value` or `source.formula` + `source.inputs`.
Reviewers see these optional `source` keys: `system`, `query`, `review_url`, `computed_at`,
`computation`, `classification`, `data`.

Every render records which element shows which fact:

| Output | Where the provenance appears |
|---|---|
| SVG | `<title>` tooltips, plus an embedded `<metadata>` block |
| PowerPoint | Speaker notes |
| Review files | `fontes.md` and `sources.json` |

- `spinagram facts <specs>` lists every fact used, per diagram.
- An unknown fact id fails `check` and `render`.

HTML slides can use the same placeholders through `spinagram.facts.render_html`.
